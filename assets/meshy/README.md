# Meshy parts

Meshy only supplied gray geometry. Color, glow, and finishes are USD materials. The live stage in `assets/cudacycle_visual.usda` does not import these GLBs. Canopy, seat, and track were authored as prims.

| File | What it is |
| --- | --- |
| `prompts/` | Text I used for each part |
| `hull.glb` | One export that is in this repo |
| `wheel.glb` / `robot.glb` | Same kind of export. Not in the repo. Not required to run |

Shared exclusions: `no background, no base, no ground plane, no text, no logos, no extra copies, no floating fragments, no smoke, no particles, no energy trails, no glow`

Export GLB only. Light gray primer. You do not need Meshy to start the twin.
